# Plennie

Aplicação mobile de organização financeira pessoal desenvolvida com HTML, CSS e JavaScript.

## Funcionalidades

- Cadastro de renda mensal, despesas recorrentes, dívidas e gastos avulsos
- Lista de desejos com estimativa de planejamento mensal
- Controle de vaquinha individual e coletiva
- Agenda de eventos com estimativa de economia mensal
- Personalização da cor de fundo
- Salvamento local dos dados usando `localStorage`

## Como executar

Abra o arquivo `index.html` em um navegador moderno.

## Observações

- Os dados ficam armazenados localmente no navegador por meio de `localStorage`; não há banco de dados ou sincronização entre usuários.
- As opções de conexão com Google, Apple ID, Instagram e e-mail são demonstrações visuais e não realizam autenticação real.
- O projeto carrega fontes e ícones de serviços externos, então algumas partes visuais podem depender de conexão com a internet.
